# 경력사항
* 현대카드 Feebiz사업팀 (2년)
  - 구독 서비스 마케팅 데이터 분석 및 보험·케어서비스 채널 운영

< 주요 성과 >
1. 데이터 분석을 통한 비즈니스 문제 해결
* 채널 팝업 노출 감소 원인 분석 및 영업 손실 방지
  - 상황 : 서비스 가입의 80%를 차지하는 팝업 노출수가 전년 대비 18% 감소
  - 분석 : SQL 기반 로그 데이터 분석(팝업 우선순위/일자별 세분화) 수행
  - 결과 : 팝업 노출 규칙 코드 오류 발견 및 수정
  - 성과 : 팝업 노출 정상화 및 불필요한 영업 손실 예방, 시스템 이상 조기 발견으로 리스크 차단
* 하이브리드 카드 결제 가능성 발굴을 통한 타겟 확장
  - 상황 : 유의사항 문구상 ‘결제 불가’로 안내되던 하이브리드 카드의 실제 결제 사례 확인
  - 분석 : 결제 로그 분석 및 시스템 검증
  - 결과 : 하이브리드 카드 보유 고객 대상 추가 마케팅 추진
  - 성과 : 기존 비대상 고객군을 신규 유입층으로 전환 → 잠재 고객 기반 확장

2. 고객 행동 데이터 기반 상품 전략 수립
  - 상황 : 카드발급 내 유료 서비스 ‘하이웨이케어(고속도로 사망 보상)’ 판매 실적 지속 저조
  - 분석 : 고객군별 가입 패턴, 연령별 선호도 분석
  - 결과 : 고객이 일상적 리스크 보장을 선호함을 파악 → ‘마이폰(휴대폰 파손 보상)’ 상품으로 대체 제안
  - 성과 : 전환 후 판매율 2배 상승, 고객 만족도 향상

3. 마케팅 커뮤니케이션 개선
  - 상황 : 반복된 광고 메시지 노출로 고객 반응률이 점차 둔화
  - 분석 : 상품별 특성과 시즌 트렌드를 반영한 마케팅 문구 및 메시지 제안
    (예: 여름철 ‘휴대폰 파손 보상’ → 해양스포츠 연결, 보이스피싱 보장 → 실사례 기반 메시지)
  - 결과 : 캠페인 시 해당 문구 활용으로 고객 주목도 및 반응률 향상
  - 성과 : 차별화된 커뮤니케이션 전략 기여, 재직 기간 중 구독형 서비스 유지회원 40만 → 120만 명 성장에 기여

4. 고객 경험(UX) 개선 및 전환율 최적화
* 가입 플로우 단순화
  - 상황 : 가입 절차 중 특정 단계에서 고객 이탈률이 높게 발생
  - 분석 : 고객 행동 로그 분석으로 입력 과정별 이탈률, 가입률, 해지율 데이터 도출
  - 결과 : 불필요한 확인 단계 제거 및 UI 개선 제안 → 필수 정보 우선 안내
  - 성과 : 가입률 상승 및 해지율 개선
* 상품 안내 페이지 UI 개선
  - 상황 : 텍스트 위주 페이지로 인한 상품 이해도 저조
  - 분석 : 페이지 클릭 로그 분석을 통해 핵심 정보 전달 구간 식별
  - 결과 : 시각적 요소 강화 페이지로 개편
  - 성과 : 상품 페이지 탐색률 및 가입률 상승

5. 업무 효율화 및 데이터 프로세스 개선
* 반복 리포트 산출 프로세스 개선
상황 : 주간/월간 실적 리포트 작성에 하루 이상 소요
분석 : 리포트 생성 과정 내 반복 쿼리 및 수작업 병목 구간 파악
결과 : SQL을 활용한 리포트 쿼리 구조 재설계
성과 : 작성 시간 1일 → 1시간 단축, 데이터 분석 업무 집중도 향상
* 데이터 추출 정확도 개선 및 업무 효율화
상황 : 담당 MD 퇴사로 인한 데이터 관리 공백 및 추출 오류 발생
분석 : 로그 데이터의 행동 시퀀스를 역추적하여 유입 경로, 클릭 패턴별 채널 특성을 식별
조치 : SQL 쿼리 개선으로 채널별 데이터 정확도 향상, 분석 과정과 기준 문서화
성과 : 데이터 분석 신뢰도 및 활용성 강화, 안정적 데이터 관리 기반 마련으로 정규직 전환 대상자로 선정
